# Personal Tunnel

Личный VPN-клиент для iPhone. Это независимая модификация VPN Direct / sing-box for Apple: без аккаунтов, оплаты, рекламы и аналитики. Серверы и подписки добавляет пользователь.

Этот репозиторий собирает приложение. Полный изменённый исходный код с историей лежит в `personal-tunnel-source.bundle`.

- Версия: **1.3.0 (173) beta 5 — PTBeta**
- Коммит исходного кода: `f950c89caf5cff13e956862ce81a3e1e0774223d`
- Bundle ID: `com.personaltunnelapp`
- Лицензия: GPL-3.0-or-later. Авторство sing-box и VPN Direct сохранено в `LICENSE` и `NOTICE`.

## Что проверено

Проверено вручную на iPhone автором сборки: протоколы и типы подписок из таблицы ниже со статусом «проверено», без вылетов и подтормаживаний интерфейса. Остальное не тестировалось на устройстве. Поддержка добавляется после того, как автор сможет проверить её сам.

| Протокол / формат | Статус |
|---|---|
| VLESS (Reality, TLS, XTLS-Vision) | проверено |
| VMess | проверено |
| Trojan | проверено |
| Shadowsocks | проверено |
| Hysteria2 | проверено |
| TUIC | проверено |
| WireGuard / AmneziaWG | проверено |
| Транспорты TCP, WebSocket, gRPC и другие | проверено |
| NaiveProxy, xHTTP, MASQUE | в сборке, не проверено автором |
| Подписки Remnawave / Happ с HWID | проверено |
| Подписки — Base64-список ссылок | проверено |
| Одиночные ссылки (`vless://`, `ss://` и т.п.) | проверено |
| sing-box JSON, Clash YAML, Xray JSON | в сборке, не проверено автором |
| Tailscale, OpenVPN, OpenConnect, Mieru, ShadowsocksR | не входят в сборку |

Ядро — форк [`Leadaxe/sing-box-lx`](https://github.com/Leadaxe/sing-box-lx), закреплённый в `core/VERSION` исходников. Через ядро идёт весь трафик, а отдельного аудита этого форка не было.

## Приватность

У приложения нет собственного сервера, и оно ничего не отправляет разработчику. Само оно выходит в сеть, только чтобы загрузить подписки, проверить соединение и выполнить TCP-пинг серверов. Каждый такой запрос виден на экране «Настройки → Прозрачность → Сетевая активность приложения». Отправку HWID можно выключить отдельно для каждой подписки. Подробно: `docs/PRIVACY.md` в исходниках.

## Сборка

Workflow `.github/workflows/personal-ios.yml`:

1. Проверяет контрольные суммы бандла и коммит.
2. Запускает тесты парсера и проверку блокировки рекламы на закреплённом ядре.
3. Собирает Libbox только с нужными протоколами.
4. Компилирует iOS-приложение и упаковывает неподписанный IPA.

Хэш исходного коммита попадает в приложение («О приложении» и экран сетевой активности). Так видно, из какого кода собрана копия. Для установки IPA нужно подписать вместе с Network Extension. В репозитории нет ни ссылок подписок, ни ключей подписи.

Восстановить исходники:

```sh
git clone --branch audit/independent-client personal-tunnel-source.bundle source
cd source
git submodule update --init --recursive
```

## Версия 1.3.0 beta 5 (PTBeta)

Бета-сборка, не проверена на устройстве. Включает все изменения beta 4.

- Края подписки больше не анимируются: свёрнутая карточка сразу имеет ту же шапку, отступы и скругления, что и раскрытая. При раскрытии меняется только высота — нижний край съезжает и открывает список. Остальные анимации не тронуты.
- Меню по удержанию — полупрозрачное стекло с блюром во всех стилях (и в Material You), с хвостиком слева, по центру или справа в зависимости от части экрана. Появляется, «вытекая» из нажатой подписки или сервера, и так же втягивается обратно.
- Hysteria / Hysteria2 из Xray JSON-подписок (Remnawave, формат Xray 26 с `finalmask` и `quicParams`) теперь импортируются, а не отбрасываются: пароль, обфускация Salamander/Gecko, смена портов и скорость Brutal. Маски, которых нет в sing-box, по-прежнему отклоняются явно.
- gRPC: поддержка уже есть (VLESS, VMess, Trojan — ссылки, Xray JSON, Clash), изменений не требовалось.
- «Проверка соединения» в современном стиле: новый вид, журнал открывается обычной навигацией — исправлены вёрстка журнала и кнопка «назад».

## Версия 1.3.0 beta 4 (PTBeta)

Бета-сборка, не проверена на устройстве. Включает все изменения beta 3.

Новый стиль «Material You» (Material 3 Expressive) — отдельный дизайн, а не перекрашенный «Современный». Расположение и жесты как в «Современном».

- Цвет: полная тональная схема Material 3 (primary, secondary, tertiary, нейтральные палитры) из одного исходного цвета; роли по токенам Material 3.
- Главная: кнопка подключения в форме «печенья» из библиотеки форм M3 Expressive. При подключении перетекает в круг, при подключении медленно вращается, при нажатии пружинно сжимается. Тональный чип статуса и карточка сервера.
- Навигация: панель Material 3 с индикатором-таблеткой 64×32.
- Настройки: крупный заголовок, сегментированные списки Expressive (зазор 2 pt, углы 20/4), иконки в тональных кругах, переключатели Material 3.
- Серверы: тональные карточки с углами 28, выбранный сервер — таблетка secondary container.
- Меню по удержанию — непрозрачное тональное меню Material; скруглённый шрифт.

Бета-сборка, не проверена на устройстве.

## Версия 1.3.0 beta 2 (PTBeta)

Бета-сборка, не проверена на устройстве: изменения написаны без Xcode, компиляцию проверяет workflow.

- Раскрытие и скрытие серверов стало плавнее. Анимируется только видимая часть списка, за 0,3–0,5 с в зависимости от расстояния. Раньше анимировалось ~920 pt за 0,32 с, и видимая часть пролетала за 4–6 кадров.
- Края плашки (зазор, скругления, прозрачность списка) теперь меняются на всём ходе анимации, а не защёлкиваются в первые и последние миллиметры.
- Меню по удержанию — своя карточка вместо системного popover со стрелкой. Появляется там же, у пальца: пружиной вырастает из точки касания, исчезает коротким сжатием. Плотный материал, мягкая тень, тонкая обводка, разделитель перед «Удалить». Касание вне меню сразу его закрывает.
- При открытом меню подписка подсвечивается целиком, до краёв плашки. Раньше подсветка была вложенной и края оставались незалитыми.
- Material You без изменений, его переделка запланирована отдельно.

## Версия 1.3.0 beta 1 (PTBeta)

Бета-сборка, не проверена на устройстве: изменения написаны без Xcode, компиляцию проверяет workflow.

- Свайп серверов и подписок теперь один и тот же системный. Удержание открывает меню быстрее (0,22 с), меню переработано: ровные строки, колонка иконок, одинаковые отступы.
- Новое раскрытие подписок: зазор между шапкой и списком плавно появляется на фиксированных 48 pt, а не растягивается на всю длину списка.
- Переход «Подключение ↔ Аналитика» продолжает движение пальца после отпускания, без остановки в начале.
- При смене сервера активное или подключающееся соединение переподключается к новому серверу, неактивное остаётся выключенным.
- Импорт шрифтов: выбор файла в «Файлах» теперь применяется сразу и показывает ошибку, если шрифт не принят.
- Третий стиль интерфейса — Material You (тональные поверхности Material 3 от акцентного цвета, пилюля активной вкладки). Переключатель: «Настройки → Интерфейс».
- Убран вход через Google (схема URL, ассеты, код). Имя приложения везде «Personal Tunnel»; упоминание форка VPN Direct осталось только в лицензии и экране «О приложении».
- Ссылки виджета и ярлыков теперь `personaltunnel://`; прежняя схема `vpndirect://` принимается для совместимости.
- Анимации не отключаются в режиме энергосбережения (там такой проверки не было и не добавлено).

Файл IPA называется `PTBeta-<версия>-<сборка>-beta<N>-unsigned.ipa`. Ветка сборки: `ptbeta`.

## Версия 1.2.0

- Экран «Сетевая активность приложения» и переключатель HWID с предпросмотром заголовков.

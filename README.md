# Personal Tunnel

Личный VPN-клиент для iPhone. Это независимая модификация VPN Direct / sing-box for Apple: без аккаунтов, оплаты, рекламы и аналитики. Серверы и подписки добавляет пользователь.

Этот репозиторий собирает приложение. Полный изменённый исходный код с историей лежит в `personal-tunnel-source.bundle`.

- Версия: **1.4.2 (178)** — релиз
- Коммит исходного кода: `866a2b8457fc0b25bd8b7af51621c1aa65d94580`
- Bundle ID: `com.personaltunnelapp`
- Лицензия: GPL-3.0-or-later. Авторство sing-box и VPN Direct сохранено в `LICENSE` и `NOTICE`.

## Что проверено

Проверено вручную на iPhone автором сборки: протоколы и типы подписок из таблицы ниже со статусом «проверено», без вылетов и подтормаживаний интерфейса. Остальное не тестировалось на устройстве. Поддержка добавляется после того, как автор сможет проверить её сам.

| Протокол / формат | Статус |
|---|---|
| VLESS (Reality, TLS, XTLS-Vision) | проверено |
| VMess | проверено |
| Trojan | проверено |
| Shadowsocks | проверено |
| Hysteria2 | проверено |
| TUIC | проверено |
| WireGuard / AmneziaWG | проверено |
| Транспорты TCP, WebSocket, gRPC и другие | проверено |
| NaiveProxy, xHTTP, MASQUE | в сборке, не проверено автором |
| Подписки Remnawave / Happ с HWID | проверено |
| Подписки — Base64-список ссылок | проверено |
| Одиночные ссылки (`vless://`, `ss://` и т.п.) | проверено |
| sing-box JSON, Clash YAML, Xray JSON | в сборке, не проверено автором |
| Tailscale, OpenVPN, OpenConnect, Mieru, ShadowsocksR | не входят в сборку |

Ядро — форк [`Leadaxe/sing-box-lx`](https://github.com/Leadaxe/sing-box-lx), закреплённый в `core/VERSION` исходников. Через ядро идёт весь трафик, а отдельного аудита этого форка не было.

## Приватность

У приложения нет собственного сервера, и оно ничего не отправляет разработчику. Само оно выходит в сеть, только чтобы загрузить подписки, проверить соединение и выполнить TCP-пинг серверов. Каждый такой запрос виден на экране «Настройки → Прозрачность → Сетевая активность приложения». Отправку HWID можно выключить отдельно для каждой подписки. Подробно: `docs/PRIVACY.md` в исходниках.

## Сборка

Workflow `.github/workflows/personal-ios.yml`:

1. Проверяет контрольные суммы бандла и коммит.
2. Запускает тесты парсера и проверку блокировки рекламы на закреплённом ядре.
3. Собирает Libbox только с нужными протоколами.
4. Компилирует iOS-приложение и упаковывает неподписанный IPA.

Хэш исходного коммита попадает в приложение («О приложении» и экран сетевой активности). Так видно, из какого кода собрана копия. Для установки IPA нужно подписать вместе с Network Extension. В репозитории нет ни ссылок подписок, ни ключей подписи.

Восстановить исходники:

```sh
git clone --branch audit/independent-client personal-tunnel-source.bundle source
cd source
git submodule update --init --recursive
```

## Версия 1.3.1.1

Релиз. Включает все изменения 1.3.1 (углы карточек подписок не тронуты). Сборка не проверена на устройстве: изменения написаны без Xcode, компиляцию проверяет workflow.

Тест задержки серверов переделан.

- **Отключение VPN больше не ждёт теста.** Раньше каждая проверка через прокси была блокирующим вызовом Libbox в общем пуле потоков Swift. 8–12 таких вызовов по 5 с занимали весь пул, а остановка VPN выполняется в том же пуле, поэтому она ждала конца теста. Теперь проверки идут в отдельной очереди, тест отменяется сразу, и уже полученные результаты сохраняются. Отключение и подключение VPN, смена подписки, смена сервера при работающем туннеле и падение туннеля сначала останавливают тест. Пока тест идёт, кнопка пинга работает как «Стоп» (Classic, «Современный», Material You).
- **Две стадии.** Этап 1 — TCP-соединение с сервером в обход VPN, таймаут 1,5 с. Это только фильтр: недоступные серверы помечаются и пропускают этап 2, а время соединения не используется для сортировки. Этап 2 — generate_204 через сам сервер, таймаут 3 с, для всех прошедших этап 1. UDP-протоколы (Hysteria, TUIC, WireGuard) идут сразу на этап 2. Этап 2 возможен только для подписки, запущенной в VPN; без VPN доступна только TCP-проверка.
- **Параллельность.** До 30 TCP-проверок и до 20 URL-тестов одновременно, остальные ждут в очереди. Лимит памяти расширения VPN на iOS около 50 МиБ, поэтому при росте памяти расширения число URL-тестов автоматически снижается до 14, 8 и 2.
- **Порядок и вывод.** Сначала проверяются видимые на экране, избранные, закреплённые и текущий серверы, остальные — в фоне. Результаты появляются по мере готовности. Classic пересортировывает список с анимацией не чаще раза в секунду. В «Современном» и Material You порядок пользователя сохраняется; в меню «⋯» появилась опция «Сортировать по задержке», и с ней строки плавно переезжают. Сервер можно выбрать до конца теста.
- **Кэш 2,5 минуты.** Повторное открытие списка проверяет только серверы без свежего результата. В заголовке списка показано время последнего замера или прогресс теста.
- **Пометка «нестабильный»**: за последние замеры разброс задержки больше 50 % от среднего или часть замеров не ответила.
- **«Подключаться к лучшему серверу»** (Настройки → Измерение задержки, по умолчанию выключено). Выбирает сервер с минимальной задержкой по свежим URL-тестам, нестабильные пропускаются. Срабатывает при подключении и после ручного теста при включённом VPN.
- Номер версии из четырёх частей указан по вашему запросу. Apple документирует для версии три части; установку подписанного IPA это, насколько известно, не блокирует, но на устройстве не проверено.

Файл IPA: `PersonalTunnel-1_3_1_1-175-unsigned.ipa`. Подробности: `docs/device/2026-11-09-latency-test-1311.md` в исходниках.

Релиз (не бета). Включает все изменения 1.3.0 beta 1–6. Сборка не проверена на устройстве: изменения написаны без Xcode, компиляцию проверяет workflow.

Быстрые повторные нажатия разворачивают движение из текущего положения. Раскрытие на странице управления подписками использует ту же пружину.
- Режим энергосбережения анимации не отключает (iOS там ограничивает частоту до 60 Гц).
- Классический стиль не затронут: у его секций нет скруглённых карточек подписок.

- Переход «Подключение ↔ Аналитика» продолжает движение пальца после отпускания, без остановки в начале.
- При смене сервера активное или подключающееся соединение переподключается к новому серверу, неактивное остаётся выключенным.
- Импорт шрифтов: выбор файла в «Файлах» теперь применяется сразу и показывает ошибку, если шрифт не принят.
- Третий стиль интерфейса — Material You (тональные поверхности Material 3 от акцентного цвета, пилюля активной вкладки). Переключатель: «Настройки → Интерфейс».
- Убран вход через Google (схема URL, ассеты, код). Имя приложения везде «Personal Tunnel»; упоминание форка VPN Direct осталось только в лицензии и экране «О приложении».
- Ссылки виджета и ярлыков теперь `personaltunnel://`; прежняя схема `vpndirect://` принимается для совместимости.
- Анимации не отключаются в режиме энергосбережения (там такой проверки не было и не добавлено).

Файл IPA называется `PTBeta-<версия>-<сборка>-beta<N>-unsigned.ipa`. Ветка сборки: `ptbeta`.
